# FrameLab · 二维平面框架结构分析器

一个**纯前端、零依赖**的二维平面框架结构分析工具，运行在浏览器中。采用**直接刚度法**对梁柱框架进行线弹性分析，可生成位移云图、弯矩图、剪力图与轴力图，并支持在任意截面读取内力值（SAP2000 风格的定位点）。

> 单文件 `index.html`，无需安装、无需后端，双击或用浏览器打开即可使用。

**在线演示**：https://song4875343.github.io/framelab/

## ✨ 功能特性

### 建模
- **网格快速生成**：输入跨数、层数、跨度、层高，一键生成多跨多层框架。
- **可交互建模**：图面点击新增节点；依次点选两个节点生成杆件（自动判别柱/梁）。
- **单元编辑**：移动、复制（带偏移并继承材料/截面/刚度）、删除选中节点/杆件。
- **节点坐标编辑**、**单元离散数**（每根杆件划分为若干有限元单元）可调。
- **边界条件**：固定端 / 铰支 / 辊轴（Ux 或 Uy）/ 自由，图形化显示支座。
- **一键示例**：「载入示例」快速生成 2 跨 3 层带荷载的演示模型。

### 材料与截面
- **材料库**：钢材 Q235 / Q345、混凝土 C30 / C40、铝 6061，或自定义（弹性模量 E、泊松比 ν）。
- **截面库**：矩形、圆形、工字形（工字形含 h、b、tw、tf 参数）。
- 自动计算截面特性 **A、I、A_s**，并由材料 + 截面导出单元刚度：
  `EA = E·A`，`EI = E·I`，`GA = G·A_s`，`G = E / 2(1+ν)`。
- 亦可在「单元」页直接给出 EA/EI/GA 手动覆盖（覆盖优先于材料/截面）。

### 荷载
- **节点荷载**：Fx、Fy、M。
- **杆件荷载**：均布荷载、集中荷载、梯形局部荷载（可叠加多条），并以 SAP2000 风格绘制**箭头 + 外轮廓线**。
- 荷载符号、荷载数值可分别开关；**荷载图比例**可缩放。

### 分析
- 二维梁柱单元（含**剪切变形**，Timoshenko 梁，GA→∞ 时退化为欧拉-伯努利梁）。
- 杆件荷载按**一致等效节点力**（Hermite 形函数 + 高斯积分）转换；内力沿杆长积分恢复（均布荷载下弯矩为抛物线）。

### 可视化
- **位移云图**（jet 色标）：按节点总位移幅值沿杆件着色。
- **弯矩图 / 剪力图 / 轴力图**：可多分量叠加显示，**内力图比例**可调，可标注内力数值。
- **内力定位点**：拖动滑杆，在所选杆件上定位并实时显示该截面的 **N / V / M**；右侧面板同时绘制**荷载、轴力、剪力、弯矩四张小图**，并用同步定位线标出数值。
- **视图缩放 / 平移**：滚轮缩放、中键拖动平移、「适应窗口」复位。
- 结果面板（画布左下角）：顶点侧移、最大总位移、最大弯矩/剪力/轴力、节点与杆件数。

### 交互
- 左键多选、右键取消选择。
- 建模工具：选择 / 新增节点 / 新增杆件（右键或 `Esc` 退出）。

## 🚀 使用方法

1. 下载或克隆本仓库：

   ```bash
   git clone https://github.com/song4875343/framelab.git
   ```

2. 直接用浏览器打开 `index.html`（推荐 Chrome / Edge / Firefox 最新版），或访问在线演示。

3. 在左侧「网格生成」设置跨数与层数，或使用「新增节点 / 新增杆件」手工建模；亦可点击「载入示例」。

4. 在右侧图面选择节点或杆件，在弹出窗口的 **单元 / 荷载 / 内力 / 材料 / 截面** 分页中进行编辑。

5. 在「显示内容」中切换 **位移云图 / 内力图**，观察变形与内力分布。

## 🔌 脚本接口（可选）

页面暴露了 `window.FrameLab` 便于嵌入与自动化（例如批量截图）：

```js
FrameLab.demo();              // 载入演示模型
FrameLab.setView("disp");     // "disp" | "force"
FrameLab.selectMember(id);    // 选中指定杆件（null 取首根）
FrameLab.selectLoaded();      // 选中首根带荷载的杆件
FrameLab.openTab("force");    // 切换弹窗分页
FrameLab.setStation(0.35);    // 定位点位置（0~1）
FrameLab.state();             // 获取模型 / 结果数据
```

## 📐 计算原理

| 项目 | 说明 |
| --- | --- |
| 单元类型 | 二维梁柱单元（2 节点 × 3 自由度：u、v、θ） |
| 刚度矩阵 | 含剪切柔度参数 φ = 12EI/(GA·L²) 的 Timoshenko 梁单元 |
| 材料/截面 | EA = E·A，EI = E·I，GA = G·A_s（G = E/2(1+ν)） |
| 荷载转换 | Hermite 形函数一致等效节点力，4 点高斯积分 |
| 内力恢复 | 由杆端力 `f = k·T·u − p` 沿杆长积分得到 V(x)、M(x)；轴力 N 为常数 |
| 边界条件 | 逐自由度约束（固接 / 铰支 / 辊轴 / 自由） |
| 求解 | 高斯消元（列主元） |

**单位约定**：长度 m、力 kN、弯矩 kN·m、刚度 EA(kN)、EI(kN·m²)、GA(kN)。荷载“垂直杆件、向下为正”。

### 截面特性公式

| 截面 | A | I | A_s |
| --- | --- | --- | --- |
| 矩形 (b×h) | b·h | b·h³/12 | 5/6·A |
| 圆形 (d) | πd²/4 | πd⁴/64 | 0.9·A |
| 工字形 (h,b,t_w,t_f) | 2b·t_f + (h−2t_f)·t_w | [b·h³ − (b−t_w)(h−2t_f)³]/12 | h·t_w |

## 🧪 验证

内置算例已与解析解核对：

- 悬臂梁均布荷载：端部挠度 `qL⁴/(8EI)`、固端弯矩 `qL²/2`；
- 简支梁均布荷载：跨中弯矩 `qL²/8`；
- 简支梁跨中集中力：跨中弯矩 `PL/4`；
- 多跨多层框架：柱底剪力之和 = 总水平力（平衡校验）。
